# Fictional sample data / 虚构样例

- `sample-profiles.json`: two versions of a fictional candidate, used by the interactive demo. This is a demo data container, not an importable extension backup.
- `sample-backup.json`: the same two versions in the format accepted by the extension's **导入备份** action. Importing can replace existing saved versions; export any existing data first.
- `sample-resume.zh-CN.txt`: a short fictional text resume retained from the original project's sample fixture, suitable for trying local text parsing.

All examples are for demonstration. They are not Ringing Song's real resume or application history. The synthetic phone-like value in the TXT fixture is an example only and must not be used for contacting anyone.

所有资料均为演示样例，不代表项目作者的真实简历。导入备份后需要点击「保存资料」才会保存版本库。
