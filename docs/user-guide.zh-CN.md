# Resume Refill 使用说明

一个本地优先的 Chrome / Edge 浏览器扩展，用来识别常见网申表单并在用户确认后填充简历资料。

## 当前能力

- 导入 PDF、DOCX 或 TXT 简历，在浏览器本地解析并写入可编辑资料表
- 支持创建、命名、切换和删除多个独立简历版本；原有单版资料会自动迁移为「默认简历」
- 新建版本从空白资料开始并立即要求重新上传对应简历，不会复制或混入当前版本内容
- 填充面板可在投递前快速选择「本次使用」的简历版本，切换后会按所选版本重新扫描网页
- JSON 备份会完整包含全部简历版本及当前选择，也兼容导入旧版单简历备份
- 解析结果不会立即保存，可人工检查、覆盖后再确认保存
- 在浏览器本地维护完整基本信息、详细教育经历、工作经历、实习经历、项目经历、校园经历、荣誉奖励、论文期刊、发明专利、语言证书技能和补充资料
- 识别常见中英文表单标签，以及标准 `autocomplete` 字段
- 每次填充前先扫描当前网页结构，将「字段含义」与「控件类型」分开识别，再生成本页专属填充方案
- 扫描当前已加载步骤中的全部必填控件；即使字段不在预设资料模型中，也会进入「新增必填项」兜底清单
- 对资料模型外的必填项分级处理：能从已保存资料可靠推导的直接填写，语义近似或无事实依据的答案集中交由用户确认
- 支持未知必填文本框、原生 / 自定义下拉、原生 / 自定义单选、富文本输入和必须确认的勾选项
- 用户确认过的补充答案按字段含义、所属模块和控件类型保存在本机；相同问题再次出现时可复用，声明和隐私勾选始终要求本人确认
- 填充前预览识别结果，并在网页中用紫色边框标记
- 填充后在网页右下角显示带状态宠物的进度组件，按模块列出完成度和遗漏字段
- 一键填充时会识别各重复模块的「添加 / 新增」按钮，按资料条数自动创建填写区块后逐条填入
- 如果招聘网站把已保存的项目精确错放进实习模块，小助手会在填充前移除错位副本，并在项目模块重新创建和填写
- 支持常见日期范围、单选项、原生下拉框、Ant Design / 北森 Phoenix 自定义下拉框、月份日历和省市级联选择
- 对没有 `name`、`id`、原生 `required` 或 ARIA 标签的组件，会沿字段容器与模块标题反向建立语义边界；导航栏搜索框会被排除，避免误识别成职位字段
- 支持北森一类以 `div` 实现的单选按钮、弹层下拉、地区选择器和年月面板，并在真正点击选项后回读页面显示值
- 同一个字段可按网页实际结构自动切换适配器；例如「籍贯」可以填入文本框、原生下拉、可搜索下拉或省 / 市级联控件
- 支持 MokaHR 一类把下拉显示值与搜索输入框分开的组件；选项会被真正点击并在填充后校验，不再只改表面文字
- 适配吉利 Moka 表单的校内任职、校园经历描述和独立年月字段；“是否全日制”会将所选教育经历的学习形式转换为是 / 否
- 支持独立两格年月和四格起止年月；按字段标题区分开始、结束和获奖时间，兼容只读下拉、带“年 / 月”后缀和零补齐月份
- 支持飞书招聘一类用可点击文字实现的起止年月区间；按组件结构识别两个日期入口，分别选择年份和月份，忽略仅用于焦点的隐藏输入框，并在页面重绘后重新定位、回读校验；教育、实习和项目等模块均可复用
- 自定义选项会点击内部文字所在的交互节点；搜索型国家下拉会尝试“中国大陆 / 中国”等同义词，并且只在当前控件所属弹层中匹配
- 学校国家、省 / 州、城市按每条教育经历独立保存；不会借用个人国家，学校所在地的历史答案按学校绑定
- 成绩排名等必填项即使已有简历资料但未写入，仍可在面板确认；多条教育经历的答案编号保持稳定，选择后页面重绘也会重新定位控件
- 国内手机号会识别“区号 + 号码”组合控件，分别填写 `+86` 和 11 位手机号
- 下拉填充会做同义值转换、等待异步选项、精确匹配并回读校验；无法可靠匹配时会提示手动确认，不会随便选择第一项
- 选择技能类型等上游字段后会重新扫描页面，把随后出现的外语语种、开发语言或其他技能字段继续填完
- 对 MokaHR 的教育和实习年月拆分下拉，会按同一条经历绑定开始年、开始月、结束年和结束月，避免多条经历串位
- 如果网站自动解析出职责文字，但同一条经历的公司或职位仍为空，小助手会将该条目判为不完整解析并用已保存资料修正职责
- 简历导入时会把技能自动归类为外语语种、证书、开发语言和其他技能，并保留语言考试成绩
- 默认保留网页上已经填写的内容，可手动开启覆盖
- 兼容普通表单及多数 React/Vue 控制的输入框事件
- JSON 导入、导出备份
- 不读取密码、不上传资料、不自动点击提交
- 仅在你主动点击扩展时临时访问当前页面，不申请长期读取所有网站的权限
- 面向国内求职场景，不包含海外工作许可或签证担保资料

## 安装

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本仓库的 `extension/` 目录。
5. 首次安装会打开资料页；导入简历、检查解析结果后点击「保存资料」。

## 使用

1. 在资料页为第一份简历命名，导入 PDF、DOCX 或 TXT 简历并检查解析结果。
2. 需要其他版本时点击「新建版本并上传」，命名后重新选择该岗位方向的简历文件。
3. 检查每一版自动填入的模块，手动修改不准确的内容并保存。
4. 打开公司的网申页面并进入实际表单。
5. 点击浏览器工具栏里的「简历填充小助手」，在「本次使用」中选择对应版本。
6. 查看扫描结果；小助手会显示识别字段数量，并按页面控件类型生成填充方案。
7. 点击「一键填充」；小助手会先补足经历区块，再分阶段扫描、填写、回读校验，并在网页右下角显示模块进度。
8. 如果出现「新增必填项」，检查智能建议、补充没有事实依据的答案，然后点击「确认并填写以上答案」。
9. 检查所有信息后再由你手动提交。

## 已知边界

- 小助手默认只自动「新增」缺少的重复区块；唯一会自动移除的情况，是网页实习条目的名称与已保存项目名称完全一致、且不匹配任何已保存实习公司时，以修复招聘网站自身的解析错位。
- 无法识别按钮所属模块，或网站要求先完成上一步才能新增时，会在进度组件中提示手动处理。
- 已支持常见的省 / 市级联下拉、地址选择弹窗和年月拆分控件；少数依赖画布、封闭 Shadow DOM 或必须联网搜索的高度定制组件仍可能需要网站适配。
- 自适应扫描会在每次点击时重新读取当前已加载的表单；如果网站把后续字段放在未进入的步骤或尚未加载的标签页中，需要先进入该步骤再重新扫描。
- 「补齐必填项」覆盖当前已加载并可交互的表单；后续步骤、条件触发后才出现的字段和验证码，需要进入相应步骤后再次扫描。
- 成绩单、证书、专利文件和作品集等附件不会自动上传，请在提交前手动选择文件。
- 图片扫描版 PDF 暂不包含 OCR；如果没有可复制文字，请改用 DOCX 或文字版 PDF。
- 简历版式差异很大，自动解析结果需要人工检查后再保存。
- 浏览器内置页、扩展商店、PDF 查看器等受保护页面无法注入扩展。
- 网站结构变化后，字段识别规则可能需要更新。

## 开发验证

使用 Node.js 22.14 或更高版本，运行 `npm ci` 后执行 `npm test`。
回归用例使用实际观察到的 Moka / Sugar 结构差异，覆盖内部菜单点击节点、无外层选项包装的日期菜单、年月拆分、选中后输入框替换和占位符消失、国家同义词搜索、全日制转换、多条教育经历与学校所在地的绑定、脚本版本迁移及失败反馈。
飞书招聘的日期用例覆盖文字区间入口、多条项目与实习的绑定、异步弹层、整表重绘、保留已有日期与覆盖开关、必填项提示、禁用选项和页面回退后的失败校验。
填充面板会检查网页脚本版本，并在主动扫描或填充时更新旧脚本；不需要为了更新网页脚本而刷新尚未保存的网申表单。面板顶部会显示实际使用的代码版本。安装信息或权限变更仍需在扩展管理页重新加载。

## 隐私设计

资料使用 `chrome.storage.local` 保存在当前浏览器配置中。扩展没有后端服务，也不会自动提交申请。导出的 JSON 备份包含完整个人信息，请妥善保管。

导入的原始 PDF、DOCX 或 TXT 文件不会保存；解析结束后，只保留你确认保存的结构化字段。
